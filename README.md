# Propósito del Proyecto 
Esta aplicación web está diseñada para analizar datos de venta de automóviles usados de manera interactiva. Permite a los usuarios explorar visualmente la información contenida en un conjunto de datos de anuncios de venta de coches.

¿Qué funcionalidad proporciona?

La aplicación ofrece las siguientes características:

Visualización interactiva: Genera histogramas dinámicos para analizar la distribución de datos
Interfaz amigable: Utiliza botones y casillas de verificación para que el usuario controle qué gráficos mostrar
Análisis del odómetro: Se enfoca específicamente en mostrar la distribución del kilometraje de los vehículos
Gráficos responsivos: Los gráficos se ajustan automáticamente al ancho del contenedor para una mejor experiencia visual
Tecnologías utilizadas:

Streamlit: Para crear la interfaz web interactiva
Plotly: Para generar gráficos interactivos y atractivos
Pandas: Para el manejo y procesamiento de datos
Experiencia del usuario:

El usuario puede hacer clic en un botón o marcar una casilla para generar instantáneamente un histograma que muestra cómo se distribuyen los valores del odómetro en el conjunto de datos de vehículos usados.
